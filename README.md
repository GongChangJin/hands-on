# GongChangJin Hands-on

새로운 기술을 직접 실행하고, 프로젝트에 사용할 수 있는지 짧은 호흡으로 검증하는 공간입니다.

각 실험은 하나의 명확한 질문에서 시작합니다. 단순한 사용법 복사보다 실제로 실행한 결과, 한계와 적용 판단을 남기는 것을 목표로 합니다.

## 실험 흐름

```text
planned → active → validated
              └──→ stopped
```

| 상태 | 의미 |
| --- | --- |
| `planned` | 질문과 실험 범위를 정함 |
| `active` | 직접 구현하고 확인하는 중 |
| `validated` | 결과와 프로젝트 적용 판단을 기록함 |
| `stopped` | 중단 이유와 현재까지의 결과를 기록함 |

## 실험 추가하기

1. `experiments/README.template.md`를 `experiments/<YYYY-MM-DD>-<topic>/README.md`로 복사합니다.
2. 해당 디렉터리 안에 실험 코드와 실행에 필요한 파일을 함께 둡니다.
3. 중첩된 Git 저장소를 만들지 않습니다.
4. 화요일·목요일 세션이 끝날 때 결과와 다음 행동을 갱신합니다.
5. 독립 실행·배포·제출이 필요한 수준으로 커지면 별도 프로젝트 레포로 승격합니다.
