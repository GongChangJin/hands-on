# 04. Multimodal Agent

> 이미지와 텍스트를 함께 사용하면 UI 오류를 일관된 구조로 분석할 수 있는가?

## 프로젝트 정의

- **상태:** `planned`
- **참여자:** `@ukkhnn`, `@us788`
- **역할:** 이미지·화면 상태를 해석하는 전문 Agent
- **선행 프로젝트:** Agent Evaluation
- **후행 프로젝트:** Computer-use Agent, LLM Router

## 배경과 목적

UI 스크린샷을 분석하여 오류 유형, 심각도, 화면 근거와 수정 방향을 구조화합니다. 이미지 단독 결과와 사용자 설명·DOM·접근성 정보를 함께 제공한 결과를 비교하여 Computer-use Agent에 어떤 화면 표현을 전달할지 결정합니다.

## 과제 명세

### 입력

- 정상·결함 UI 스크린샷 20장 이상
- 오류 카테고리와 정답 라벨
- 선택적인 사용자 설명, DOM 또는 접근성 정보

### 필수 구현

- 이미지 크기·포맷 표준화와 개인정보 마스킹
- 이미지 단독 분석
- 이미지와 보조정보를 결합한 분석
- 오류 종류·심각도·근거·수정 제안의 구조화 출력
- 두 입력 방식의 정확도와 비용 비교

### 산출물

- 멀티모달 분석 Agent
- 마스킹된 공통 이미지와 라벨
- 구조화된 오류 분석 결과
- 입력 구성별 정확도·비용 비교표

### 포함 범위

- 레이아웃 깨짐, 잘림, 잘못된 상태와 오류 메시지 분석
- 화면 영역에 대한 설명형 근거

### 제외 범위

- 마스킹하지 않은 개인정보 업로드
- 근거 없는 pixel-level 좌표 확정
- 브라우저 클릭·입력 실행

## 권장 기술

- Vision 입력을 지원하는 LLM API
- Pillow
- 선택적으로 OpenCV
- Pydantic 또는 JSON Schema
- DOM·접근성 snapshot 수집 도구

## 디렉터리 사용

- `shared/`: 마스킹된 이미지, 오류 taxonomy, 정답 라벨과 출력 schema
- `implementations/ukkhnn/`: `ukkhnn`의 입력·전처리 조합
- `implementations/us788/`: `us788`의 입력·전처리 조합
