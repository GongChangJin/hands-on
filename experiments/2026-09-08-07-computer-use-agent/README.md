## 알아볼 것

- 접근성 트리와 스크린샷 기반 조작의 차이
- 실패 후 화면을 다시 읽고 복구하는 루프
- 도메인·단계·행동 제한을 이용한 안전 제어

## 실험 범위

### 해볼 것

- 로컬 또는 전용 테스트 사이트에서 공통 태스크 10개 수행
- Playwright trace·스크린샷·행동 로그 저장
- 태스크마다 새 browser context와 최대 step 적용

### 하지 않을 것

- 실제 결제·메일 발송·예약·계정 변경
- 허용되지 않은 도메인 접근
- 사람 승인 없이 되돌리기 어려운 최종 제출

## 실행 방법

테스트 사이트와 태스크 정의는 `shared/`, 개인별 browser agent는 `implementations/<github-id>/`에 둡니다.
