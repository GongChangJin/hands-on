## 실험 범위

### 해볼 것

- 정상·결함 UI 스크린샷 20장 이상 구성
- 오류 카테고리와 심각도를 JSON으로 출력
- 개인정보 마스킹과 이미지 축소 전후 비교

### 하지 않을 것

- 마스킹하지 않은 실제 개인정보 업로드
- pixel-level 위치를 근거 없이 확정
- 이미지와 무관한 추측을 정답으로 인정

## 실행 방법

공통 이미지와 라벨은 `shared/`, 개인별 모델·전처리 코드는 `implementations/<github-id>/`에 둡니다.
