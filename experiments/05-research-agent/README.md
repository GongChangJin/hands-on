# 05. AI Research Agent

> 논문 검색부터 비교·근거 정리·후속 가설 제안까지 출처를 잃지 않고 자동화할 수 있는가?

## 프로젝트 정의

- **상태:** `planned`
- **참여자:** `@ukkhnn`, `@us788`
- **역할:** 학술 정보 검색·검증·비교를 담당하는 전문 Agent
- **선행 프로젝트:** Agent Evaluation
- **후행 프로젝트:** LLM Router, 통합 시스템

## 배경과 목적

연구 질문을 검색식으로 바꾸고 논문을 수집·중복 제거·검증한 뒤 방법론과 결과를 비교합니다. 논문이 실제로 주장한 내용과 Agent가 새로 추론한 가설을 명확하게 분리합니다.

## 과제 명세

### 입력

- 하나의 공통 연구 질문
- 검색 API와 검색 조건
- 접근 가능한 초록 또는 원문
- 논문 식별자 검증 규칙

### 필수 구현

- 검색어 확장과 논문 검색
- DOI·arXiv ID·paperId 기준 중복 제거와 유효성 확인
- 핵심 주장·방법론·데이터·결과 추출
- claim-evidence 비교표 생성
- 출처가 연결된 요약과 별도 후속 가설 생성

### 산출물

- 검증된 논문 목록 10~20편
- 검색 조건과 필터
- claim-evidence 표
- 인용이 연결된 비교 리포트
- BibTeX 또는 구조화된 참고문헌

### 포함 범위

- 공개 API를 통한 논문 탐색
- 합법적으로 접근 가능한 초록·원문 분석
- 검색 결과 재현에 필요한 조건 기록

### 제외 범위

- 접근권한 우회
- 유효하지 않은 논문·DOI 인용
- Agent 가설을 논문 결론으로 표현

## 권장 기술

- Semantic Scholar Academic Graph API
- arXiv 또는 Crossref API
- Python `httpx`
- `pypdf` 또는 `pdfplumber`
- BibTeX 생성 도구와 Pydantic

## 디렉터리 사용

- `shared/`: 연구 질문, 검색식, 필터, 검증 논문 ID와 claim-evidence schema
- `implementations/ukkhnn/`: `ukkhnn`의 검색·분석 파이프라인
- `implementations/us788/`: `us788`의 검색·분석 파이프라인
