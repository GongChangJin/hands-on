## 알아볼 것

## 실험 범위

### 해볼 것

- `small`, `balanced`, `frontier`, `local` 논리 라우트 구성
- 동일 질문을 all-frontier 기준선과 비교
- 모델별 token, 비용, p50/p95 latency 기록

### 하지 않을 것

- 모델 ID를 애플리케이션 코드에 직접 고정
- 라우터 자체 비용을 제외한 비교
- 품질 평가 없이 비용만 비교
