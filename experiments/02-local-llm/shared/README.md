# 공통 자료

## 평가 데이터

[`evals/tasks.jsonl`](evals/tasks.jsonl)은 분류 8개, 구조화 추출 8개, 짧은 질의 8개로 구성된 24개 `TaskRequest`다. 모든 태스크는 도구를 허용하지 않고, 응답 JSON Schema와 결정적 기대 답을 실행 전에 고정한다.

## 판정 규칙

- 성공: JSON Schema 통과와 기대 답의 결정적 일치가 모두 필요하다.
- 구조 준수율: 답의 정확성과 별도로 JSON Schema 통과율을 계산한다.
- 속도: 전체 지연시간과 첫 콘텐츠 수신 시간의 p50/p95, Ollama의 실제 생성 token/s를 기록한다.
- 자원: 모델 파일 크기와 Ollama가 보고한 accelerator memory를 기록한다.
- 비용: 로컬 호출비는 0달러로 기록하되 장비·전력 비용은 미산정으로 명시한다. API는 provider가 반환한 usage와 공식 요율을 사용해야 한다.
- 실패: 파싱, schema, 오답, adapter 오류와 안전 위반을 분리하며 결과에서 제거하지 않는다.

모델 가중치와 대형 캐시는 커밋하지 않는다. 라이선스는 모델 배포 원문과 Ollama에 포함된 라이선스를 함께 확인하고, 모델·양자화·context·기기·실행기 버전을 결과에 기록한다.
