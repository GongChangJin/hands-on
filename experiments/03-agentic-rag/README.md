# 03. Agentic RAG + Tool Use

> Agent가 검색·계산 도구를 스스로 선택하면서 검증 가능한 근거를 포함한 답변을 만들 수 있는가?

## 프로젝트 정의

- **상태:** `planned`
- **참여자:** `@ukkhnn`, `@us788`
- **역할:** 문서 기반 질의와 결정적 도구 사용을 담당하는 전문 Agent
- **선행 프로젝트:** Agent Evaluation
- **후행 프로젝트:** LLM Router, 통합 시스템

## 배경과 목적

일반 RAG에서 한 단계 확장하여 Agent가 검색 필요 여부, 계산 도구 사용, 검색 결과 적합성과 재검색 여부를 결정하게 합니다. 답변 품질뿐 아니라 근거와 도구 사용 과정도 함께 평가합니다.

## 과제 명세

### 입력

- 공통 문서 3개 이상
- 검색형·계산형·혼합형·답 없음 질문
- `retriever`, `calculator` 도구 정의

### 필수 구현

- 문서 수집·분할·색인
- 검색 또는 직접 응답 선택
- 결정적 계산 도구 호출
- 검색 결과 적합성 판정과 제한된 재검색
- 문서 ID·위치·계산식을 포함한 `AgentResult`

### 산출물

- 실행 가능한 Agentic RAG
- 평가 질문 15개 이상
- 검색·계산·재검색 `ToolTrace`
- 근거 정확도와 실패 사례 비교표

### 포함 범위

- 로컬 공통 문서 검색
- 결정적 계산
- 근거 기반 답변과 답 없음 처리

### 제외 범위

- 실제 금융 의사결정 자동화
- 일반 웹 검색
- 검색 문서 안의 명령 실행
- 근거 없는 추측을 성공으로 판정

## 권장 기술

- Python 3.11 이상
- LangGraph 또는 직접 구현한 상태 머신
- Chroma·Qdrant·FAISS 중 하나
- Pydantic
- PDF·텍스트 추출 도구
