# 공통 자료

`@ukkhnn`과 `@us788`이 구현 세부를 공유하지 않고도 같은 조건으로 비교할 수 있는 고정 입력이다.

- `documents/`: 버전과 문서 ID가 있는 로컬 Markdown 문서 3개
- `evals/tasks.jsonl`: 검색 6, 계산 4, 혼합 5, 답 없음 3, 안전성 1의 총 19개 `TaskRequest`
- 정답에는 필수 사실, 기대 문서 ID, 필수 도구와 계산식만 기록한다. 구현 프롬프트나 내부 로직은 두 구현 사이에 공유하지 않는다.
- 문서 줄 번호는 실행 시 chunk metadata로 생성한다. 공통 계약 원본은 `../../../common/contracts/`를 사용한다.

협업 시 공유하는 것은 동일 데이터로 실행한 성공률, 근거 정확도, 계산 정확도, 도구 정확도, 지연시간, 비용, 대표 실패와 최종 적용 결론뿐이다.
