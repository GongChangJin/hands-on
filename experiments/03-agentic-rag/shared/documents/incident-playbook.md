# 장애 등급과 목표

P1은 전체 서비스 중단 또는 데이터 손실 위험이다. 최초 응답 목표는 15분, 복구 목표는 4시간이다.

P2는 핵심 기능의 심각한 성능 저하이다. 최초 응답 목표는 1시간, 복구 목표는 1영업일이다.

P3는 우회 방법이 있는 일반 결함이다. 최초 응답 목표는 1영업일, 해결 목표는 5영업일이다.

# 백업과 복구

지식 색인 metadata와 설정은 매일 03:00 KST에 백업하고 14일 동안 보관한다. 원본 지식 문서는 별도 원본 저장소의 보존 정책을 따른다.

복구 훈련은 분기마다 실시한다. 훈련에서는 새 Qdrant collection에 복원한 뒤 문서 수, corpus fingerprint, 표본 질의의 근거 위치를 대조한다.

# 사고 기록

P1과 P2 사고는 종료 후 3영업일 이내에 원인, 영향 범위, 탐지 시각, 복구 조치와 재발 방지 항목을 포함한 회고를 남긴다.
